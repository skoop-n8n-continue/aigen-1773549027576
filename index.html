n8n Workflow Architecture Overview

Architecture Diagram

n8n workflow └─ HTTP Request POST /run ──────────────► initiator Lambda (30s) │ │ creates DynamoDB job │ ◄── 202 { jobId, statusUrl } ────────── │ invokes worker async │ │ │ n8n Wait node (waits up to 20 min) ▼ │ worker Lambda (900s) │ │ clones GitHub repo │ │ runs agent (cn or claude) │ │ git add / commit / push │ │ uploads files to S3 │ │ marks job "completed" └─ ◄── POST callback_url { response } ── ─┘ ▼ DynamoDB ◄─── GET /status/{jobId}

Workflow Steps

1
HTTP Request POST /run n8n triggers the initiator Lambda via an HTTP POST request
2
Initiator Lambda 30s timeout Creates a DynamoDB job record, invokes the worker Lambda asynchronously, returns 202 with jobId & statusUrl
3
n8n Wait Node up to 20 min Pauses the workflow and waits for a callback from the worker Lambda
4
Worker Lambda 900s timeout Clones the GitHub repo, runs the agent (cn or claude), commits & pushes changes, uploads files to S3, marks job as "completed"
5
Callback & Status Worker POSTs to callback_url with the response; DynamoDB status is readable via GET /status/{jobId}
